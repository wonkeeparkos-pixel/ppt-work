# FBT 카페 저장소 — 사용법

네이버 카페 게시판 글을 구글드라이브 `FBT` 폴더에 모아두고,
필요할 때 **그 데이터 안에서만** AI에게 검색·질문하기 위한 안내서입니다.

## 전체 그림

```
카페 글 복사 → FBT 폴더의 게시판별 통합 문서에 붙여넣기 → NotebookLM/Claude로 질문
```

옵시디언은 필요 없습니다. 구글드라이브 + NotebookLM(또는 드라이브가 연결된 Claude)만으로 충분합니다.

## 1. 드라이브 폴더 만들기 (최초 1회)

1. [drive.google.com](https://drive.google.com) → 새로 만들기 → 폴더 → 이름 `FBT`
2. `FBT` 폴더 안에 **게시판별·연도별 구글 문서**를 만듭니다. 글마다 파일을 만들지 말고
   한 문서에 이어 붙이는 방식입니다. 예:

```
FBT/
├── 공지사항_2026        (구글 문서)
├── 자유게시판_2026      (구글 문서)
└── 질문답변_2026        (구글 문서)
```

파일이 너무 커지면(수백 페이지) `자유게시판_2026상반기`처럼 반기/분기로 나눕니다.

## 2. 글 저장 양식

카페에서 글을 복사한 뒤, 해당 게시판 문서 맨 아래에 아래 양식으로 붙여넣습니다.
양식 전체 예시는 `양식_게시판명_연도.md` 파일을 참고하세요.

```
──────────────────────────────
[제목] 글 제목
[작성자] 닉네임
[날짜] 2026-07-21
[링크] https://cafe.naver.com/카페주소/글번호
[본문]
글 내용 전체를 여기에 붙여넣기
```

- 헤더 4줄(제목/작성자/날짜/링크)은 꼭 채웁니다. AI가 답변할 때 "어느 글에서 나온
  내용인지" 짚어주는 근거가 됩니다.
- 댓글 중 중요한 것이 있으면 본문 아래 `[댓글]` 줄을 추가해 붙입니다.

## 3. AI로 질문하기

### 방법 A — NotebookLM (추천)

올린 자료 **안에서만** 답하고, 답변마다 출처 문장을 표시해줍니다.

1. [notebooklm.google.com](https://notebooklm.google.com) → 새 노트북 만들기
2. 소스 추가 → Google Drive → `FBT` 폴더의 문서들 선택
3. 채팅창에 질문하면 올린 글에만 근거해 답변합니다.
4. **새 글을 추가한 뒤에는** 노트북에서 해당 소스를 클릭 → "Google Drive와 동기화"를
   눌러야 최신 내용이 반영됩니다.

### 방법 B — Claude (구글드라이브 연동)

Claude에 구글드라이브를 연결해두면 대화하면서 이렇게 요청하면 됩니다:

> "드라이브 FBT 폴더 안에서만 찾아서 답해줘. ○○에 대해 언급된 글이 있어?"

검색에 더해 요약·표 정리·문서 생성 같은 후속 작업까지 이어갈 수 있는 것이 장점입니다.

## 4. 운영 요령

- 글을 저장하는 시점을 정해두세요(예: 주 1회 몰아서 추가). 미루면 쌓입니다.
- 문서 이름은 반드시 `게시판명_연도` 규칙을 지키세요. AI가 파일 단위로 검색하므로
  이름이 곧 색인입니다.
- 과거 글이 많다면 최근 글부터 거꾸로 채우는 것이 실용적입니다. 오래된 글은
  검색 수요가 생길 때 채워도 됩니다.
