# 친절이 통증을 바꾼다 — 근거 기반 환자 소통 가이드 (30장)

척추 중재시술·사지 관절 주사를 시행하는 의원 임상의를 위한 발표자료입니다.
두 원문 자료를 하나의 흐름으로 연결했습니다.

- **왜(근거)** — 노시보·플라시보·공감·불안의 과학 (Varelmann 2010, Lang 2005 등)
- **어떻게(원칙)** — 진료실 4가지 핵심 원칙
- **진료실에서** — 시술 전·중·후 3단계 멘트 & 말 바꾸기 카드
- **시술별·안전** — 척추 중재시술, 관절 주사, 미주신경성 실신·바늘 공포 대응

## 결과물
- `친절_통증소통_가이드_30.pptx` — 편집 가능한 파워포인트 (16:9, 30장)
- `친절_통증소통_가이드_30_미리보기.pdf` — 빠른 확인용 미리보기

## 다시 빌드
```bash
pip install python-pptx pillow
python3 build_deck.py        # .pptx 생성
python3 pdf_export.py 친절_통증소통_가이드_30.pptx 미리보기.pdf   # PDF 미리보기(선택)
```

## 디자인 메모
- 슬라이드당 핵심 메시지 하나, 제목 최소화
- 한글 폰트: 맑은 고딕(뷰어 환경에 맞춰 자동 대체)
- ○ = 권장 표현 / × = 피할 표현 (한국식 O·X 관례)
