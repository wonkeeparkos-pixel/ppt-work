# 시술 멘트 매뉴얼 (의사용)

의원 진료실에서 원장이 시술 중 실제로 쓰는 문장 모음입니다.
말로 통증을 줄이고 환자 신뢰를 얻는 것이 목적입니다.

## 결과물

| 파일 | 용도 |
|---|---|
| `시술멘트_매뉴얼_의사용.pptx` | 본 매뉴얼 30장 (16:9) |
| `시술멘트_벽부착_A4.pptx` | 시술실 벽에 붙이는 요약 1장 (A4 세로) |
| `*_미리보기.pdf` | 열지 않고 넘겨보는 미리보기 |

## 구성

1. **바늘 들어가는 순간** — "따끔"은 그대로 쓰되 시간·통제로 닫는 법, 감각 단계별 표현
2. **환자가 꼭 묻는 질문** — 뼈주사·스테로이드·횟수·효과·방사선·신경 손상
3. **시술별 한마디** — 경추/흉요추 MBB, 신경근차단, 경막외, 무릎·어깨·팔꿈치
4. **곤란한 순간** — 어지럼·바늘공포·다음날 통증·효과 없음·보호자 불안

## 핵심 원칙

1. **숨기지 않는다** — 아픈 걸 아프다고 하되 짧고 담담하게
2. **끝을 알려준다** — "몇 초면 지나가요"로 시간을 닫는다
3. **권한을 준다** — "불편하면 말씀하세요"로 멈출 수 있게 한다

### '따끔'에 대하여
'따끔' 같은 중립적 예고 자체는 통증을 높이지 않습니다(Vijayan 2015).
통증을 키우는 건 위협적·과장 표현("벌에 쏘이듯", "여기가 제일 아파요")과
아픔을 강조·반복하는 것입니다(Varelmann 2010; Lang 2005).
피부를 뚫는 감각을 '누르는 느낌'이라 하면 사실과 달라 신뢰를 잃습니다.
