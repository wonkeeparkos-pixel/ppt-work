# 만성 정맥부전·정맥류(CVI) 요약본
## 병태생리 · 주된 호소 · 치료 핵심

작성일 2026-07 · 교육·연구 참고용.

## 한눈에 보는 핵심
- **병태생리:** 판막 부전 → 역류 → **지속적 정맥고혈압** → 근육펌프 부전이 고착 → 백혈구 포획·염증 → 혈관벽 리모델링 → **부종→색소침착→지방피부경화→궤양(C3→C6)**.
- **주된 호소:** 다리 **무거움·둔통·부종**, **오래 서면/저녁에 악화, 다리 올림·보행·압박으로 완화**, 정맥류·헤모시데린 색소·내과부 궤양(감각은 정상).
- **감별:** NLC(스트레칭 완화 근경축)·RLS(움직임 완화 충동)·PAD(허혈 파행·거상 시 악화)·PN(양말형 감각소실)과 구분 — CVI는 **정맥 소견 + 거상반응**이 결정타. **압박 전 ABI로 PAD 배제.**

## 중재 핵심(논문 기반)
- **EVLA/RFA(열소작):** 적합 복재정맥 역류의 1차. CLASS 5년 — 레이저·수술의 QoL·비용효과가 폼보다 우월.
- **폼 경화요법(Rabe 2014):** POL/STS, Tessari 1:4~1:5, 세션당 ≤10 mL — 저비용이나 재개통·재치료 많음.
- **CAC/VenaSeal(VeClose):** 36개월 폐쇄율 CAC 94.4% ≈ RFA 91.9%, tumescent 불필요.
- **EVRA:** 정맥성 궤양 + 표재역류 → 조기 소작이 치유 HR 1.38(P=0.001), 중앙 56 vs 82일, 재발↓.

## 압박치료 핵심(1차·근간)
- **증상·부종:** 10–20 mmHg만으로도 위약 대비 유의 개선(Amsler 2008); **매일 신는 최저 유효압**이 관건.
- **궤양 치유:** 압박>무압박(Shi 2021), **다성분·탄력·4층붕대 우월**(O'Meara 2012). **시행 전 ABI 필수.**
- **재발 예방:** 압박이 재발↓(Nelson 2014), **표재역류 교정 병용 시 4년 재발 56%→31%**(ESCHAR).
- **종아리펌프 운동(Padberg 2004):** 박출률 개선의 직접 RCT 근거. 다리 올림·체중감량은 근거등급 낮으나 무위험 보조.

## 핵심 메시지
1. **압박치료가 1차·근간(ABI 확인 후)** — 부종·증상·궤양 치유·재발예방 전 영역 최다 근거. 2. **근본 교정은 표재역류 소작** — 적합 복재정맥엔 열소작(EVLA/RFA) 1차, 정맥성 궤양엔 조기 소작(EVRA). 3. **경구 정맥활성약물은 보조**(MPFF 근거 최다). 4. **ESWT는 CVI 증상 직접근거 없음**, 정맥소작이 RLS/야간경련을 '치료'한다는 근거는 저질 관찰뿐 — 인과 단정 금지.
