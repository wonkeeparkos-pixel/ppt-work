## 구성 (40장) — 임상에서 기술로

| 장 | 내용 |
|---|---|
| 1–2 | 표지 · 목차 |
| **3–5** | **적응증과 금기** — 무엇을 노리는가, 진단별 근거 수준, 절대/상대 금기 |
| **6–9** | **효과** — 숫자(NNT 4/6), 진단별 차이(LESS 시험), 접근법별, 예측인자와 한계 |
| 10 | 전환 — "효과는 약이 표적에 닿았을 때의 이야기다" |
| 11–14 | 해부 — LOR은 가설이다 · 경막외강 · 황색인대 정중부 결손 · Okada 후경막강 |
| 15–23 | **LOR 인지법 5계열 24가지** — 음압 / 저항소실 / 기구 / 영상 / 전기·광학 |
| 24–26 | **안전 술기** — 시술 전 · 진입 · 확인 |
| 27–36 | **조영제 패턴 판독** — 정상 1 + 실패 7가지 (사진 슬롯 10칸) |
| 37–40 | 합병증 · MSIS 합의 · Take-home 8 · 참고문헌 |

발표 흐름은 **적응증 → 효과 → (전환) → 기술** 순이다. 앞의 임상 파트가 "왜 이 시술을 하는가"를 세우고,
10장의 전환 슬라이드가 "그 효과는 약이 표적에 닿았을 때의 이야기"라는 논지로 기술 파트를 연다.

## 알아둘 점

- **실제 조영제 사진은 아직 비어 있습니다.** 이 세션 컨테이너는 조직 정책상 외부 사이트 접속이
  차단되어(PMC·학술지 모두 403) 논문 그림을 내려받을 수 없었습니다. 요청대로 **AI 그림이나
  모식도로 대체하지 않고**, 출처·Figure·직링크가 적힌 사진 슬롯으로 남겨 두었습니다.
  → `02_에셋/contrast_real/README.md` 참고
- 참고문헌은 **서지정보·초록 수준**에서 확인했습니다. 원문 전문 대조는 하지 못했으므로
  수치를 인용하실 때는 원문 확인을 권합니다.
- 교육·연구 참고용이며 개별 환자의 진료 판단을 대체하지 않습니다.
