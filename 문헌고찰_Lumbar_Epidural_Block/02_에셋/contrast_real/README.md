# 실제 조영제 패턴 사진 — 삽입 안내

## 왜 사진이 아직 비어 있는가

이 세션 컨테이너는 **조직 정책상 외부 사이트 접속(egress)이 차단**되어 있습니다.
`curl`, `WebFetch` 모두 PMC·Europe PMC·Wikimedia·학술지 서버에 대해 `403 (CONNECT tunnel failed)`을 반환합니다.
따라서 **논문에 실린 실제 투시 영상을 이 환경에서 직접 내려받을 수 없습니다.**

사용자 요청대로 **AI 생성 그림이나 제가 그린 모식도는 넣지 않았습니다.**
대신 PPT와 아티팩트의 해당 자리에는 **출처·Figure 번호·직링크가 적힌 사진 슬롯**을 만들어 두었습니다.

## 사진을 채우는 두 가지 방법

### 방법 1 — Google Drive에 올리기 (가장 간단, 연결 확인됨)

Google Drive 커넥터는 서버측에서 동작하므로 **정상 작동합니다.**
아래 파일명 그대로 Drive 아무 폴더에나 올려주시면, 제가 내려받아 PPT와 아티팩트에 삽입합니다.

### 방법 2 — 이 폴더에 직접 넣기

`02_에셋/contrast_real/` 에 아래 파일명으로 저장한 뒤 재빌드 스크립트를 실행하면 됩니다.

```bash
python3 scripts/build_ppt.py     # 사진이 있으면 자동으로 슬롯에 삽입
```

## 저작권 주의

- PMC **Open Access subset (CC BY / CC BY-NC)** 논문의 그림은 **출처를 명시하면** 교육 목적 재사용이 가능합니다.
- 그 외 학술지 그림은 출판사 허락이 필요합니다.
- **가장 안전하고 강의 신뢰도도 높은 선택은 원장님 본인 증례의 C-arm 영상**입니다 (환자 식별정보 제거 필수).

## 슬롯 동작 방식

- 사진이 **없으면**: 출처·Figure 번호·직링크가 적힌 빈 프레임이 표시됩니다 (그림 대체물 없음).
- 사진이 **있으면**: 자동으로 그 자리에 삽입되고 캡션에 출처가 붙습니다.
