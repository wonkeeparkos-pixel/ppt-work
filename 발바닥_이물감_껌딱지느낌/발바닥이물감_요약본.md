# 발바닥 이물감(껌딱지 느낌)·지간신경종 요약본
## 감별 · 진단 · 치료 핵심 (보존 · 주사 · 시술 · 수술)

작성일 2026-07 · 교육·연구 참고용.

## 한눈에 보는 핵심
- **호소:** "걸을 때 발바닥에 껌딱지/돌멩이/뭉친 양말이 밟히는 이물감" + 전족부 작열통 + 인접 발가락 저림. 신발·체중부하 시 악화, 탈화·마사지로 완화 → **지간신경종(몰톤 신경종)**의 전형.
- **병태생리:** 총족지신경의 압박·견인성 신경병증(진성 종양 아님·신경주위 섬유화). 호발 **3번 web space > 2번**, 심부 횡중족인대 하방. 중년 여성·좁은/굽 높은 신발.
- **함정:** '이물감' 단독 진단력은 약함(민감도 43~53%). '발가락 사이 딸깍(clicking)' 호소가 특이적(특이도 0.96). 지간 압통·방사통·Mulder·초음파를 종합.
- **감별:** 중족골통·족저판 손상·굳은살(IPK)·족저 섬유종·지간 점액낭염·종자골염·족근관/말초신경병증·잔류 이물을 배제·공존 확인.

## 감별 빠른표(레드플래그)
| 단서 | 시사 진단 |
|---|---|
| 통증이 중족골두·관절 '바로 아래', 발가락 들림/벌어짐 | 족저판 손상·중족골통 |
| 아치/근막에 만져지는 단단한 결절 | 족저 섬유종(Ledderhose) |
| 눈에 보이는 각화·점상출혈 | 사마귀 / 굳은살(IPK) |
| 넓게 퍼지는 저림·야간악화·내과후방 Tinel 양성·양측성 | 족근관 / 말초신경병증 |
| 천자 외상력·한 점 고정 종괴 | 잔류 이물 / 육아종 |

## 치료 단계 요약
| 단계 | 치료 | 근거 | 위치 |
|---|---|---|---|
| 1차 | 신발 교정 + 중족골 패드/돔(**중족골두 근위 5~11mm**) | Hastings 2007·Landorf 2020(간접·생역학) | 최우선·저위험 |
| 2차 | 초음파 유도 스테로이드+마취제 주사(2~3회 제한) | Thomson 2013 RCT(단기) | 보존 실패 시 |
| 2차(대안) | 알코올(에탄올) 경화주사 | Hughes 2007 / Gurdezi 2013(5년 효과 축소) | 선택적·근거 약함 |
| 시술 | ESWT / 고주파(RFA) / 냉동신경융해 | Seok·Fridman RCT / Llombart 2025 / Moulin 2024 | 예비적·보조 |
| 수술 | 신경절제(표준) / 신경감압(신경보존) | Reichert 2016 / Choi 2022·Villas 2008 | 불응성 |

## 주사기법 핵심(논문 기반)
- **접근:** 초음파 유도 **배측(dorsal) in-plane** — 족저 지방패드 침착·탈색·위축 회피. 25G(23~27G).
- **스테로이드:** 트리암시놀론 40mg 또는 메틸프레드니솔론 20~40mg + 1% 리도카인 1~2mL(총 1~3mL). 초음파 유도 vs 촉지 결과차 없음(Mahadevan 2016)이나 안전상 유도 권장.
- **알코올:** 20~30% 에탄올 0.5~1mL, 1~3주 간격 3~7회 시리즈(비표준). 흡인·저항 확인, 신경내 주입 회피.

## 핵심 메시지
1. 이물감 단독으로 확진 금물 — **지간 국한 압통·방사통·Mulder·초음파**를 종합하고 감별을 나란히 배제.
2. **패드는 중족골두 '아래'가 아니라 '근위(뒤)'**에 — 배치 오류가 실패의 흔한 원인.
3. 스테로이드는 단기 효과·**증상 조절/수술 지연** 목적, 2~3회 제한, **배측 접근**.
4. 불응성 표준 치료는 **신경절제**(만족 ~80%); 감각저하는 합병증이 아닌 내재적 결과, 잔여 신경종 예방이 관건.
5. 몰톤 치료는 전반적으로 근거수준이 낮음(Cochrane 2024) — 성공률을 단일 수치로 확언하지 말 것.
